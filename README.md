📖 القرآن الكريم

تطبيق ويب متكامل للقرآن الكريم، يعمل مباشرة من المتصفح بدون تثبيت.

🌐 تجربة مباشرة: https://mamhaz.github.io/QuranKarim

✨ المميزات

• 🎧 أكثر من 100 قارئ من مختلف أنحاء العالم الإسلامي
• 📻 راديو مباشر لكل قارئ
• 📖 مصحف كامل مع تفسير الميزان آية بآية
• ⬇️ تنزيل السور للاستماع بدون إنترنت
• 🔍 بحث شامل في القراء، السور، والآيات (عبارة كاملة)
• 🎯 فلتر ذكي للسور (متوفرة، مُنزّلة، غير متوفرة)
• 📊 إحصائيات القارئ (عدد السور، الحجم، الحالة)
• 💬 همسة قرآنية — آية عشوائية عند فتح التطبيق
• 🎨 تخصيص كامل — 25+ خط عربي، 10 ألوان، وضع مظلم
• ⏳ مؤقت نوم شامل للسور والراديو
• 💾 حفظ الجلسات — استئناف تلقائي للاستماع والقراءة
• 🗄️ إدارة البيانات — حذف ذكي حسب الحجم، الأقدم، أو غير المستخدمة

• HTML + CSS + JavaScript — بدون مكتبات خارجية
• IndexedDB — لتخزين النصوص والتفسير
• Cache API — لتخزين الملفات الصوتية
• PWA — قابل للتثبيت على الجوال
• Font Awesome 6.5 — للأيقونات
• Google Fonts — للخطوط العربية
